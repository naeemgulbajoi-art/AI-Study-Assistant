# AI Study Assistant

## Overview
AI Study Assistant is a student-focused website designed to support study activities.

## Technologies Used
- HTML
- CSS

## Project Files
- `index.html` — Main website page.
- `style.css` — Website design and styling.
- `package.json` — Project configuration.

## How to Run
1. Open or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## Purpose
This project is designed to provide a simple website for students.
